# Architectural Decision Records

Esta pasta armazenará os Architectural Decision Records (ADRs) do LeadPulse Analytics.

Cada ADR deverá registrar o contexto, a decisão, as alternativas consideradas e as consequências relevantes. Os registros serão adicionados somente quando decisões reais forem tomadas; nenhum ADR fictício é mantido nesta fundação.
